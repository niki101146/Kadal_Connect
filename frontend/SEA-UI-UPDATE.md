# Kadal Connect — Sea UI refresh

## Included
- Complete sea-inspired visual refresh using deep ocean, lagoon, sea-glass and foam colours.
- Responsive layout refinements for phones, tablets and desktop.
- Floating Kadal Assistant chatbot with quick prompts and built-in FAQs for marketplace, fishermen, prices, sea safety, accounts and emergency contacts.
- Existing page components, navigation and API interactions are preserved.

## Chatbot note
The assistant is a client-side FAQ helper. It does not call an AI service or access private account/order data. To make it AI-powered, connect a secure backend endpoint and keep provider API keys on the server.
